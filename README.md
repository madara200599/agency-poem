A deterministic Python program that writes one original poem about agency: what happens to the power to act when a person builds a second pair of hands, lends them the work, and takes them back changed. Standard library only; the same poem, byte for byte, on every run, written to /output/entry.txt.

## Run it

```sh
python3 main.py
```
