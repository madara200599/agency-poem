# agency-poem

Write the best poem about agency - $250 bounty on make.fun: a deterministic Python program that writes one original poem about agency.

## Run

```
python3 main.py
```

It writes exactly one poem to `/output/entry.txt` (1-1000 characters, deterministic, Python standard library only).

## The poem

The program writes a 16-line original poem about agency: choosing to act instead of waiting - the morning's question answered with one's own hands, the unlocked door, the small brave choices that add up, and becoming the author of one's own days.
